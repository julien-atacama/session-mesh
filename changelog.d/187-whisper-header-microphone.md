- **Hold the microphone in a local terminal header to dictate without automatic submission.**
  Desktop transcripts enter the original prompt without Enter; phones stage an editable draft for
  manual Send. Input and recovery remain bound to the original session incarnation. A disabled
  microphone explains the cause in its tooltip and accessible status text.
  See [Voice dictation](docs/features.md#voice-dictation).
